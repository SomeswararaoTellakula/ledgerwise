Your AP team answers the same invoice question every month.
The software flags it. Nobody remembers the answer.

I built Ledgerwise: an AP agent that resolves invoice exceptions the way your desk did last time.

What made it work:

→ Recall before deciding: "how were this vendor's variances resolved, and why?"
→ Store the amount, not just the outcome. +2.8% approved ≠ +4.2% approved.
→ Act only on 2+ consistent human precedents. Never on its own past calls.
→ Bank changes always go to a human.

Before memory: 0% auto-resolved.
After: 60–100% from week 3 on replay data, 0 wrong calls.

Hindsight agent memory made it practical: retain decisions with reasons, recall with sources, reflect for vendor briefs.
